# SciFi-Generator v60.25 — Sprachmanager-Tabelle

Die Paketliste im Tab **Sprachmanager** ist ab v60.25 eine vollständig interaktive Tabelle.

## Sortieren

Ein Klick auf einen Spaltenkopf sortiert nach dieser Kategorie. Ein weiterer Klick kehrt die Sortierreihenfolge um. Das gilt für:

- Stimme
- Engine
- Qualität
- Größe
- Status

Damit können beispielsweise alle **Installiert**- bzw. **Verfügbar**-Einträge über die Statusspalte gruppiert werden.

## Spalten anpassen

Die Trenner zwischen den Spalten können mit der Maus verschoben werden. Zusätzlich können die Spaltenköpfe selbst per Drag & Drop in eine andere Reihenfolge gezogen werden.

Die eingestellten Breiten, die Spaltenreihenfolge und die zuletzt verwendete Sortierung werden zusammen mit den übrigen Anwendungseinstellungen gespeichert und beim nächsten Start wiederhergestellt. Sie werden auch in vollständige Konfigurationsprofile aufgenommen.

Beim erneuten Scannen oder Installieren eines Sprachpakets bleibt die aktuelle Sortierung aktiv. Die Tabelle deaktiviert die Sortierung nur intern kurz während des Neuaufbaus, damit Zeilen beim Einfügen nicht auseinandergerissen werden.

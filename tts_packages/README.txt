SciFi-Generator managed TTS packages
====================================

This directory is managed by the Sprachmanager tab.
Downloaded/reused Piper runtimes are stored in _engines/, cached source files in _cache/,
and installed voice models in voices/.

The release archive intentionally does not bundle the large runtime/model files.
Installing a complete package adds everything required for that voice locally.
Do not delete individual runtime files while voices are installed; use the Sprachmanager instead.
